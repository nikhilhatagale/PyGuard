# PyGuard

PyGuard is an AI-assisted Python code analysis tool developed as a final-year diploma project.

It helps developers analyze Python code, identify potential issues and security vulnerabilities, detect duplicate code, and improve code quality with AI-assisted suggestions.

## Features

- Static Code Analysis
- Security Vulnerability Detection
- Duplicate Code Detection
- AI-Assisted Code Suggestions
- Improved Code Generation
- Code Minimization
- Structural Code Metrics
- Python Code Playground

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- CodeMirror
- Groq API
